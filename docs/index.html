Tag & email routing by ticket type

For each ticket type, choose which existing Mailchimp tag to apply, and optionally override how the contact's email/name is worked out — e.g. always use one particular question as the email, or also sync a second contact (like a parent/carer) when their email differs from the attendee's own. Ticket types without a rule here get no tag and use the default email/name behavior.

Saved as config.json in the repo. Create matching merge fields in Mailchimp's audience settings first, or values will be dropped.
